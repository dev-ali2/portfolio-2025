### 🎯 Why Flutter for Portfolio Web Apps?

Here are the **top 5 advantages** of building portfolio websites with Flutter:

| 🎨 **Single Codebase** | Build once, deploy everywhere - web, mobile, and desktop from the same code |
|---|---|
| ⚡ **High Performance** | Near-native performance with smooth animations and fast loading |
| 🎭 **Rich UI/UX** | Create stunning, interactive interfaces with Flutter's powerful widget system |
| 🔧 **Easy Maintenance** | One codebase means easier updates, bug fixes, and feature additions |
| 🚀 **Future-Proof** | Easily extend to mobile apps or desktop applications later |

## 🏁 Getting Started

### Prerequisites

- Flutter SDK (3.12 or higher)
- Dart SDK
- Web browser for testing
- Code editor (VS Code recommended)

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/dev-ali2/portfolio_2025.git
   cd portfolio_2025
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Create your app write account**
   - Sign up at [your preferred service]
   - Create a new project/application

4. **Get your credentials**
   - Navigate to your app dashboard
   - Copy API keys/credentials
   - Create a `.env` file in the root directory

5. **Add temp data in data model classes**
   ```dart
   // Example: lib/shared/models/project_model.dart
   static DataModel siteData = (

     ),
   
   ```

6. **Run the app**
   ```bash
   # For web development
   flutter run -d chrome
   
   # For production build
   flutter build web
   ```
